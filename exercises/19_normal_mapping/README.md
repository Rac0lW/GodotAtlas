# 19 · 程序化法线

法线贴图的 RGB 本质上编码了切线空间方向。本题不用图片，而是用 UV 生成同类数据，从而把“采样”和“空间转换”分开理解。

## 任务

根据 UV 的正弦波生成 XY 扰动，重建合法 Z 分量，构造 TBN，把结果转换后写入 `NORMAL`。

## 验收

- 波纹密度由 `frequency` 控制。
- `normal_strength` 为零时恢复原始几何法线。
- 高强度时法线仍保持单位长度且无 NaN。

## 固定数值目标

基础色从 `vec3(0.04, 0.18, 0.2)` 插值到 `vec3(0.12, 0.72, 0.64)`，`frequency` 默认值为 `28.0`，`normal_strength` 默认值为 `0.38`，`ROUGHNESS` 固定为 `0.38`。

## 提示 1

XY 长度平方必须限制到小于 1。

## 提示 2

Z 可由 `sqrt(1.0 - dot(xy, xy))` 重建。

## 提示 3

最后仍需用 `mat3(TANGENT, BINORMAL, NORMAL)` 转换。

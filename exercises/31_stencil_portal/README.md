# 31 · 模板传送门

模板缓冲不是一张可见颜色图，而是每像素的小整数标签。写入材质先把门户区域标为 1，读取材质只在模板值等于 1 的地方显示内部场景。

## 任务

为读取 shader 添加模板读取模式：比较方式为 equal，参考值为 1。保持禁用深度写入，并用程序化网格显示门户内部。

## 验收

- 内部图案只出现在写入几何覆盖的区域。
- 读取材质不覆盖模板外像素。
- 相机移动时遮罩仍遵守场景深度关系。

## 固定数值目标

门户内部颜色在 `vec3(0.02, 0.09, 0.12)` 与 `vec3(0.12, 0.88, 0.72)` 之间混合。网格线的 `line` 为 `1.0` 时使用后一个颜色。

## 提示 1

写入 shader 已位于 `res://shared/shaders/portal_writer.gdshader`。

## 提示 2

本题需要 `stencil_mode read`。

## 提示 3

完整声明为 `stencil_mode read, compare_equal, 1;`。

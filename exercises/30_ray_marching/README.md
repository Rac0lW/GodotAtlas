# 30 · 光线步进

光线步进从相机发射一条射线，每次前进当前点到最近表面的估计距离。当距离足够小就命中，累计距离过大则认为没有物体。

## 任务

实现球体 SDF 和最多 64 次的步进循环，命中后使用表面深度与简单法线估计着色，未命中时输出背景色。

## 验收

- 中心出现有体积感的球体，而不是二维圆。
- 球体边缘稳定，没有整屏命中。
- 循环具有命中阈值和最大距离两个退出条件。

## 提示 1

球体距离为 `length(point) - radius`。

## 提示 2

射线方向由中心化 UV 和固定 Z 分量构造后归一化。

## 提示 3

用有限差分在 X、Y、Z 三个方向估计 SDF 梯度，即表面法线。

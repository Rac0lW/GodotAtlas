# 20 · SDF 基元

有向距离场用一个数表示点到边界的距离：负数在形状内部，正数在外部。`min()` 相当于并集，因此复杂图形可以由简单函数组合。

## 任务

实现圆形和矩形两个距离函数，用 `min()` 合并它们，再用窄 `smoothstep()` 生成抗锯齿遮罩。

## 验收

- 画面同时包含圆与矩形，并形成一个连通形状。
- 边缘平滑而非硬锯齿。
- 改变两个基元位置时，组合关系仍成立。

## 固定数值目标

形状外部颜色为 `vec3(0.035, 0.055, 0.09)`，内部颜色为 `vec3(0.96, 0.52, 0.16)`，Alpha 固定为 `1.0`。

## 提示 1

圆距离为 `length(p) - radius`。

## 提示 2

矩形可先取 `abs(p) - half_size`，再处理外部和内部距离。

## 提示 3

并集距离使用 `min(circle_distance, box_distance)`。

# 26 · 四元数旋转

单位四元数用一个标量和一个三维向量表示旋转。轴角转四元数后，可以用叉积公式直接旋转向量，并避免按欧拉轴依次组合带来的万向节问题。

## 任务

实现轴角到四元数的转换，以及四元数旋转向量函数。使用 `rotation_axis` 与 `angle_degrees` 旋转顶点。

## 验收

- 旋转轴在使用前归一化。
- 角度使用半角计算四元数。
- 0° 时顶点完全不变。

## 提示 1

四元数向量部分为 `axis * sin(half_angle)`，标量部分为 `cos(half_angle)`。

## 提示 2

可将四元数保存为 `vec4(xyz, w)`。

## 提示 3

旋转公式为 `v + 2.0 * cross(q.xyz, cross(q.xyz, v) + q.w * v)`。

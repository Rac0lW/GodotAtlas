# 15 · 线性光与 sRGB

光照计算应在线性空间进行，但显示设备通常使用近似 sRGB 编码。相同的线性数值直接显示会显得偏暗，编码后才符合人眼对亮度的感知。

## 任务

让上半区显示线性梯度，下半区显示经过近似 gamma `1.0 / 2.2` 编码的梯度，中间加一条细分界线。

## 验收

- 上下半区左、右端点相同。
- 中间亮度明显不同。
- 下半区使用 `pow()`，没有简单相加提亮。

## 提示 1

梯度值使用 `UV.x`。

## 提示 2

编码表达式为 `pow(linear_value, 1.0 / 2.2)`。

## 提示 3

用 `step(0.5, UV.y)` 选择上下半区。

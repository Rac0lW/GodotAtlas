# 05 · 阶段接力

顶点阶段每个顶点执行一次，片元阶段每个像素执行一次。`varying` 会把顶点输出插值后交给片元阶段，是两者之间的显式接口。

## 任务

在 `vertex()` 中把对象空间高度写入 `vertex_height`，在 `fragment()` 中把高度映射成冷暖双色渐变。

## 验收

- `vertex_height` 在顶点阶段被赋值。
- 片元阶段使用插值后的值。
- 平面颜色沿高度连续变化，不是每个三角形一块色。

## 提示 1

本题只需要传递一个 `float`。

## 提示 2

高度来自 `VERTEX.y`。

## 提示 3

用 `smoothstep(-0.5, 0.5, vertex_height)` 得到混合因子，再用 `mix()` 混色。

# 22 · 时间信号

`TIME` 是持续增长的秒数。把它放进正弦函数会得到稳定周期信号；再映射到 0 到 1，就能驱动半径、颜色或强度。

## 任务

让圆环半径以 `pulse_speed` 脉动，同时让颜色在 `color_a` 与 `color_b` 之间缓慢往返。

## 验收

- 动画循环连续，没有突然跳变。
- 半径始终大于零。
- 修改速度参数时，运动频率随之变化。

## 提示 1

周期信号为 `sin(TIME * speed)`。

## 提示 2

将它乘 0.5 再加 0.5，得到 0 到 1。

## 提示 3

圆环距离使用 `abs(length(point) - animated_radius)`。

# 27 · Game Boy 后处理

全屏后处理读取已经渲染完成的屏幕纹理，再对最终像素进行处理。像素化改变采样坐标，四色效果则量化亮度。

## 任务

把 `SCREEN_UV` 对齐到 `pixel_size` 网格，采样屏幕纹理，计算感知亮度并映射到四个固定绿色色阶。

## 验收

- `pixel_size` 增大时像素块同步变大。
- 输出只出现四种主色，而不是连续灰阶。
- 使用 `filter_nearest`，块边缘保持清晰。

## 固定数值目标

四级调色板依次为 `vec3(0.055, 0.16, 0.13)`、`vec3(0.18, 0.34, 0.22)`、`vec3(0.48, 0.58, 0.28)`、`vec3(0.78, 0.82, 0.42)`。`pixel_size` 默认值为 `5.0`。

## 提示 1

屏幕像素尺寸为 `1.0 / SCREEN_PIXEL_SIZE`。

## 提示 2

使用 `floor(pixel_coordinate / size) * size` 对齐网格。

## 提示 3

亮度权重可使用 `vec3(0.2126, 0.7152, 0.0722)`。

# 01 · 第一个片元

片元着色器会为屏幕上的每个可见像素计算输出。`UV` 是从左上到右下变化的二维坐标，`COLOR` 是本题唯一需要写入的结果。

## 任务

编辑 `exercise.gdshader`，让红色通道等于 `UV.x`、绿色通道等于 `UV.y`、蓝色通道固定为 `0.35`，Alpha 保持 `1.0`。

## 验收

- 左侧更暗，右侧更红。
- 顶部绿色较少，底部绿色较多。
- 画面完全不透明。

## 提示 1

`UV.x` 和 `UV.y` 的范围都是 0 到 1。

## 提示 2

使用 `vec4(r, g, b, a)` 组装最终颜色。

## 提示 3

最终表达式的形状是 `COLOR = vec4(UV.x, UV.y, 0.35, 1.0);`。

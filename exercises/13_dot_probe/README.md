# 13 · 点积探针

点积是方向关系的压缩表示。归一化向量同向时结果为 1，垂直时为 0，反向时为 -1。把它显示为灰度，比背公式更容易形成直觉。

## 任务

归一化 `probe_direction`，计算它与 `NORMAL` 的点积，将结果从 -1 到 1 映射到 0 到 1，再显示为灰度。

## 验收

- 面向探针方向的区域接近白色。
- 背离区域接近黑色。
- 垂直区域处于中灰，而不是被截断为黑色。

## 提示 1

不要在本题使用 `max(..., 0.0)`，否则看不到负半区。

## 提示 2

映射公式仍然是乘 0.5 再加 0.5。

## 提示 3

`float signal = dot(NORMAL, normalize(probe_direction)) * 0.5 + 0.5;`。

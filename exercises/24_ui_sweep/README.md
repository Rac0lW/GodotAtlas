# 24 · UI 扫光

扫光通常由一个移动窄带、柔和边缘和底图响应共同组成。只叠加纯白会像贴纸；让高光受基础图案调制，效果会更像材质反射。

## 任务

生成深色网格底图，构造随时间从左下移向右上的对角窄带，并把高光强度乘上底图亮度。

## 验收

- 高光沿对角线循环移动。
- 带宽由 `sweep_width` 控制。
- 深色网格区域获得的高光较弱。

## 固定数值目标

`accent` 默认值为 `vec4(0.96, 0.62, 0.18, 1.0)`，网格基础色在 `vec3(0.035, 0.055, 0.09)` 与 `vec3(0.08, 0.12, 0.17)` 之间混合。`sweep_speed` 默认值为 `0.35`，`sweep_width` 默认值为 `0.08`。

## 提示 1

对角坐标可以使用 `UV.x + UV.y`。

## 提示 2

循环位置使用 `fract(TIME * speed)`。

## 提示 3

窄带由 `1.0 - smoothstep(width, width * 2.0, abs(diagonal - position))` 构造。

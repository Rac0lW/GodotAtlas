# 34 · Value Noise

随机网格会产生硬块。Value Noise 取相邻四个角点的随机值，再用平滑权重插值，让网格之间连续过渡。

## 任务

在 8 × 8 网格上实现二维 Value Noise，使用 `smoothstep` 形状化局部坐标，并用两次 `mix` 插值四个角点。

## 验收

- 画面是连续的云状灰度，而不是独立方块。
- 放大或缩小网格频率时，纹理仍保持连续。
- 四个角点的随机值由同一个 hash 函数产生。

## 提示 1

`floor(p)` 给出当前网格，`fract(p)` 给出网格内坐标。

## 提示 2

平滑权重可以写成 `local * local * (3.0 - 2.0 * local)`。

## 提示 3

先沿 x 轴插值两次，再沿 y 轴插值一次。

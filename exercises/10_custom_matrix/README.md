# 10 · 自定义矩阵

矩阵把一组坐标轴映射到另一组坐标轴。绕 Y 轴旋转只需要处理 XZ 平面，因此可以先用一个 `mat2` 看清结构。

## 任务

根据 `angle_degrees` 计算弧度、正弦和余弦，构造二维旋转矩阵，并用它变换 `VERTEX.xz`。

## 验收

- 角度 0° 时模型不变。
- 角度 90° 时 X、Z 轴正确交换并带符号变化。
- 没有直接调用引擎节点旋转。

## 提示 1

使用 `radians()` 把角度转换为弧度。

## 提示 2

二维旋转矩阵由 `cos` 和 `sin` 组成。

## 提示 3

构造 `mat2(c, -s, s, c)` 后与 `VERTEX.xz` 相乘。

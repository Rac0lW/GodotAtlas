# 38 · UV 扰动

纹理变形通常发生在采样之前：先修改 UV，再用新的坐标读取纹理。这样同一张图就能产生水波、热浪或镜头像差。

## 任务

以屏幕中心为基准，用 `sin` 和 `TIME` 产生径向偏移，再用扰动后的 UV 采样 `screen_texture`。

## 验收

- 画面保持原有内容，但边缘出现连续的弯曲变形。
- 变形随时间平滑变化，不出现随机跳闪。
- 采样仍使用合法的屏幕纹理和 `SCREEN_UV`。

## 提示 1

先计算 `vec2 centered = SCREEN_UV - vec2(0.5)`。

## 提示 2

用 `length(centered)` 控制偏移在中心小、边缘大。

## 提示 3

把 `centered * sin(radius * 18.0 - TIME * 1.5) * 0.025` 加回 `SCREEN_UV`。

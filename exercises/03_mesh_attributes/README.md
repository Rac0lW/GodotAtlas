# 03 · 看见网格属性

三维网格不只是形状，它还携带位置、法线、UV、切线等属性。法线分量位于 -1 到 1，颜色分量位于 0 到 1，因此需要先重新映射。

## 任务

将观察空间法线 `NORMAL` 从 `[-1, 1]` 映射到 `[0, 1]`，写入 `ALBEDO`。保持 `unshaded`，让结果不受灯光干扰。

## 验收

- 球体不同朝向显示不同 RGB 颜色。
- 颜色连续，没有 UV 接缝。
- 旋转预览相机时，颜色随观察空间方向变化。

## 提示 1

区间映射可以写成乘法再加偏移。

## 提示 2

`[-1, 1] * 0.5 + 0.5` 会得到 `[0, 1]`。

## 提示 3

使用 `ALBEDO = NORMAL * 0.5 + 0.5;`。

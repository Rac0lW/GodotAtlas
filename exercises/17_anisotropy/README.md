# 17 · 各向异性高光

普通高光围绕法线近似对称。拉丝金属、头发等表面有明确纹理方向，高光会沿切线或次切线被拉长。

## 任务

把片元阶段的切线与次切线交给光照阶段，分别计算半程向量在两个方向上的投影，并用 `tangent_sharpness`、`binormal_sharpness` 控制拉伸。

## 验收

- 调换两个 sharpness 时，高光拉伸方向旋转约 90°。
- 高光仍受法线朝光程度限制。
- 切线和次切线在使用前归一化。

## 提示 1

需要半程向量 `normalize(LIGHT + VIEW)`。

## 提示 2

两个方向投影的平方适合构造椭圆指数。

## 提示 3

可以用 `exp(-tangent_term - binormal_term)` 得到平滑高光。

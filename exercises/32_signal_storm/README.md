# 32 · 综合挑战：信号风暴

最后一题不再只考一个公式。你需要把三个独立信号放在正确阶段：顶点脉动改变轮廓，Fresnel 描述观察角度，程序化噪声决定表面溶解。

## 任务

完成顶点脉动、世界空间噪声和 Fresnel。使用 `dissolve_threshold` 控制丢弃区域，在溶解边缘加入暖色发光，并写一段说明指出每个计算所在的空间。

## 验收

- 模型轮廓有连续呼吸运动。
- 溶解不是单纯上下裁切，并随时间缓慢变化。
- 轮廓光响应相机角度，溶解边缘具有独立发光色。
- README 末尾补充不少于三句的实现说明。

## 提示 1

顶点脉动适合使用对象空间法线方向移动顶点。

## 提示 2

将世界位置输入简单哈希函数，可获得不会粘着屏幕的噪声。

## 提示 3

用噪声与阈值之差构造窄边缘，再写入 `EMISSION`。

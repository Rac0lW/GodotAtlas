# 04 · 坐标空间

`VERTEX` 默认属于对象空间。移动模型时，它的数值不会改变；乘以 `MODEL_MATRIX` 后得到世界空间位置，颜色就能固定在整个场景中。

## 任务

在顶点阶段计算世界空间位置，通过 varying 传给片元阶段，再将其三个分量缩放、偏移并用 `fract()` 显示为重复色带。

## 验收

- 颜色来自世界位置，不来自 UV。
- 预览模型移动时，色带像穿过模型一样保持在世界中。
- varying 使用 `vec3`。

## 提示 1

位置向量乘矩阵时需要齐次分量 `1.0`。

## 提示 2

世界位置为 `(MODEL_MATRIX * vec4(VERTEX, 1.0)).xyz`。

## 提示 3

片元颜色可以写成 `fract(position_ws * 0.25 + 0.5)`。

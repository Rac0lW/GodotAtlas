# 35 · Voronoi 细胞

Voronoi 把每个网格单元当成一个区域，并为区域放置一个特征点。每个像素只需找到最近的特征点，就能得到细胞状结构。

## 任务

把 UV 缩放到 6 × 6 网格，搜索当前单元周围的 3 × 3 邻域，输出到最近特征点的距离。

## 验收

- 画面出现重复但不完全相同的细胞区域。
- 每个细胞中心更亮，边界由距离连续形成。
- 移动到单元边缘时，不会因为只搜索当前单元而断裂。

## 提示 1

用 `floor` 得到当前单元，用 `fract` 得到单元内坐标。

## 提示 2

两层 `for` 循环可以遍历 x、y 都为 -1 到 1 的邻域。

## 提示 3

用 `min` 保留最小距离，再用 `smoothstep` 把它变成可见亮度。

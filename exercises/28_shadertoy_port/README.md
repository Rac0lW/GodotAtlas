# 28 · Shadertoy 移植

Shadertoy 常用以像素为单位、原点位于左下的坐标；Godot CanvasItem 更常从归一化 UV 开始。移植时应先统一原点、范围、宽高比和时间，而不是机械改变量名。

## 任务

将 UV 映射到中心为零的 -1 到 1 空间，根据 `viewport_size` 修正 X 轴宽高比，再用 `TIME` 驱动三个移动波源。

## 验收

- 改变预览宽高比时，圆形结构不会变成椭圆。
- 图案随时间连续运动。
- 坐标转换集中在开头，后续公式不重复修正。

## 提示 1

中心化坐标是 `UV * 2.0 - 1.0`。

## 提示 2

X 分量乘 `viewport_size.x / viewport_size.y`。

## 提示 3

用三个不同频率与方向的 `sin()` 相加，再映射成颜色。

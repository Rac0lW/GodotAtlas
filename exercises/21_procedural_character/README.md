# 21 · 程序化角色

程序化角色并不依赖复杂公式，而依赖清晰的层次：先确定头部遮罩，再添加眼睛、鼻子与嘴，最后决定各层如何覆盖。

## 任务

用圆形距离构造头部和双眼，用圆环距离构造弧形嘴。所有部件必须从中心化 UV 推导，不采样纹理。

## 验收

- 头部以暖色显示，背景保持深色。
- 两只眼睛位置对称。
- 嘴是一条弧线，而不是填满的圆。

## 固定数值目标

背景固定为 `vec3(0.025, 0.045, 0.075)`，皮肤固定为 `vec3(0.93, 0.58, 0.25)`，线稿固定为 `vec3(0.035, 0.055, 0.08)`，Alpha 固定为 `1.0`。

## 提示 1

用 `min(left_eye, right_eye)` 合并双眼。

## 提示 2

圆环距离可以写成 `abs(length(p) - radius) - thickness`。

## 提示 3

给嘴增加 Y 方向裁切，只保留圆环下半部。

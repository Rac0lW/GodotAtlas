# 23 · 顶点波

顶点动画改变的是网格轮廓，而不是表面颜色。顶点密度会直接影响波形质量，因此预览使用高细分平面。

## 任务

根据世界无关的对象空间 X 坐标与 `TIME` 计算正弦波，把结果加到 `VERTEX.y`，并将波高传给片元阶段着色。

## 验收

- 平面轮廓实际起伏，不只是颜色移动。
- `amplitude` 为零时恢复平面。
- 相邻顶点连续，没有随机断层。

## 固定数值目标

低端颜色为 `vec3(0.03, 0.18, 0.28)`，高端颜色为 `vec3(0.14, 0.82, 0.72)`。`amplitude`、`frequency`、`speed` 默认值分别为 `0.28`、`5.0`、`1.6`。

## 提示 1

相位可以写成 `VERTEX.x * frequency + TIME * speed`。

## 提示 2

波值为 `sin(phase) * amplitude`。

## 提示 3

在修改顶点前先计算并保存波值给 varying。

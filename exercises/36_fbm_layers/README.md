# 36 · fBm 分形叠层

单层噪声只有一个尺度。fBm 把多个频率的噪声按递减振幅相加，让大形状和细节同时存在，是程序化云、岩石和烟雾的常用起点。

## 任务

复用 Value Noise，叠加 5 个 octave：每层频率翻倍、振幅减半，最后把总和作为灰度输出。

## 验收

- 画面同时包含大块变化和细小纹理。
- 增加 octave 后，细节变多但整体亮度仍在 0 到 1 附近。
- 每层采样仍然来自确定性的噪声函数。

## 提示 1

循环中维护 `frequency` 或直接把采样坐标乘 2。

## 提示 2

振幅从 `0.5` 开始，每一层乘 `0.5`。

## 提示 3

把每层 `value_noise` 乘当前振幅后累加到 `total`。

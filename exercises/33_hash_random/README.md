# 33 · 可复现随机

程序化纹理需要随机感，但每个像素都必须得到稳定结果。先把 UV 量化成网格，再用 hash 函数把网格坐标映射到 0 到 1。

## 任务

实现 `hash21(vec2)`，对 `floor(UV * 12.0)` 取样，并把结果作为灰度输出。

## 验收

- 画面由稳定的明暗网格组成。
- 相同网格位置在不同帧仍返回相同数值。
- 随机值来自 UV，不依赖额外贴图。

## 提示 1

先用 `fract` 和一个大常数打散输入坐标。

## 提示 2

`dot` 可以把两个分量混成一个新的标量。

## 提示 3

`float value = hash21(floor(UV * 12.0));` 就是每个网格取一个值。

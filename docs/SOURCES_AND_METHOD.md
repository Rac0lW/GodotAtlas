# 来源与改编方法

Shader Atlas 是供项目所有者私人使用的练习型课程。课程代码、练习描述和验证规则均为本项目重新编写；书中图片和配套资源不会复制进核心课程，也不应随项目对外分发。

## 私人教材

课程知识主线来自本机的《Godot 着色器圣经》资料：

- 第 1 章“网格组成简介”对应练习 03 至 10：属性、坐标空间、渲染阶段、世界空间、切线空间、插值、内置矩阵和自定义矩阵。
- 第 2 章“光照与渲染”对应练习 11 至 19：材质通道、Lambert、点积、Blinn-Phong、线性光与 sRGB、Fresnel、各向异性、半球光、ShaderInclude 和程序化法线。
- 第 3 章“程序化图形与顶点动画”对应练习 20 至 26：函数绘图、程序化角色、时间动画、顶点变形、UI 高光、旋转矩阵和四元数。
- 第 4 章“高级 VFX 与后期处理”对应练习 27 至 31：Game Boy 后处理、Shadertoy 移植、距离渐隐、光线步进和模板缓冲。
- 练习 01、02 是为渐进式课程补写的入门坡道；练习 32 是重新设计的综合挑战。

运行时通过 `PrivateAssetResolver` 探测 `res://assets_v17/assets`。存在时只把它视为本机参考资源入口；不存在时，课程仍使用自带几何体和程序化画面完整运行。

## 练习系统参考

课程组织借鉴 `mainmatter/100-exercises-to-learn-rust` 的方法，而不移植其 Rust 内容：

- 学习内容拆成短而连续的编号练习。
- 每题都保留可工作的 starter、独立 solution 和机器可读验收规则。
- 通过前置关系控制学习顺序，并把进度保存到本机。
- 反馈优先告诉学习者“哪个可观察条件未满足”，而不是直接公布答案。

用户提供的 `Rac0lW/godot-systems-workshop` 地址在制作时无法公开访问，因此没有复制其中实现。项目把目录、会话、预览和验证拆成独立组件，未来拿到该仓库后可以逐层对照，而不需要重写课程内容。

## 验证原则

源码契约只用于验证无法从单张图可靠判断的接口，例如 uniform、ShaderInclude 和模板比较模式。主要练习使用固定夹具渲染学习者版本与参考版本，再比较降采样图像；依赖相机运动、GPU 排序或解释能力的题目保留人工观察清单。

这种组合不会要求学习者照抄参考源码，同样的视觉结果可以由不同的正确实现通过。

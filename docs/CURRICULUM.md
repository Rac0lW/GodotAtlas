# Shader Atlas 课程蓝图

本课程面向已经会打开 Godot 场景、但尚未形成着色器心智模型的学习者。内容使用 Godot 4.7.1 和 Forward+ 渲染器，核心练习不依赖付费素材；检测到 `res://assets_v17/assets` 时，可在部分预览中启用私人参考素材。

每题遵循同一节奏：先观察错误或缺失效果，再预测需要改变的变量，随后编辑 `exercise.gdshader`，最后在 Workshop 中运行验证。starter 必须可以被项目加载，solution 必须通过对应验证。

## 模块 0：启动信号

1. 第一个片元：理解 `shader_type canvas_item`、`fragment()`、`UV` 和 `COLOR`。
2. Uniform 控制台：把硬编码颜色变成可由材质控制的参数。

## 模块 1：网格与管线

3. 看见网格属性：把法线映射到可见颜色。
4. 坐标空间：区分对象坐标和世界坐标。
5. 阶段接力：用 varying 把顶点数据传入片元阶段。
6. 世界渐变：让多个实例共享连续的世界空间着色。
7. 切线空间：构造 TBN，并把切线空间法线转回观察空间。
8. 混合、遮罩与 Alpha：用连续遮罩代替硬边判断。
9. Billboard：用内置矩阵让平面朝向相机。
10. 自定义矩阵：用二维旋转矩阵变换三维顶点。

## 模块 2：光照

11. 材质通道：理解 ALBEDO、ROUGHNESS 和 METALLIC 的职责。
12. Lambert：用法线和光线的点积构造漫反射。
13. 点积探针：把向量夹角变成灰度信号。
14. Blinn-Phong：用半程向量构造高光。
15. 线性光与 sRGB：比较数值相同但编码不同的灰度。
16. Fresnel：根据视线与法线夹角生成边缘光。
17. 各向异性：沿切线方向拉伸高光。
18. 半球光与 ShaderInclude：把可复用光照函数移出主文件。
19. 程序化法线：用 UV 导数构造切线空间扰动。

## 模块 3：程序化图形与动画

20. SDF 基元：组合圆与矩形距离场。
21. 程序化角色：只用距离函数构成人脸。
22. 时间信号：用 TIME 驱动可预测的周期动画。
23. 顶点波：让平面顶点产生连续形变。
24. UI 扫光：构造循环移动且受底图控制的高光。
25. 旋转矩阵：比较绕轴旋转与直接改坐标。
26. 四元数：用轴角四元数旋转顶点。

## 模块 4：高级 VFX

27. Game Boy 后处理：读取屏幕纹理、像素化并量化色阶。
28. Shadertoy 移植：修正坐标原点、宽高比和时间变量。
29. 距离渐隐：在世界空间中计算相机距离并控制透明度。
30. 光线步进：在片元阶段步进有向距离场。
31. 模板传送门：理解写入材质、读取材质和深度关系。

## 模块 5：综合挑战

32. 信号风暴：组合顶点脉动、Fresnel 和程序化溶解，并说明每个计算所在的坐标空间。

## 验收原则

- 目录中必须恰好有 32 个唯一练习 ID，且前置关系无环。
- 每个 README、exercise、starter、solution 和验证配置都必须存在。
- starter 可加载但不能通过最终视觉验证，solution 必须通过。
- 自动视觉验证使用固定尺寸、相机、灯光和多组参数，比较降采样图像而不是 shader 源码。
- 模板缓冲和综合创作题同时保留人工检查项，避免把 GPU 差异误判为学习错误。

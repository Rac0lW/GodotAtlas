# P03 · 混合两种颜色

`mix(a, b, amount)` 会根据 `amount` 在两个值之间平滑过渡。它是制作渐变和材质变化的常用积木。

## 任务

使用 `UV.x` 在 `vec3(0.88, 0.34, 0.15)` 和 `vec3(0.12, 0.78, 0.72)` 之间做一条水平渐变。左端使用前一个颜色，右端使用后一个颜色。

## 验收

- 当 `UV.x = 0.0` 时接近 `vec3(0.88, 0.34, 0.15)`。
- 当 `UV.x = 1.0` 时接近 `vec3(0.12, 0.78, 0.72)`。
- 中间区域平滑过渡，没有明显断层。

## 提示 1

`UV.x` 可以作为 `mix` 的第三个参数。

## 提示 2

先混合 `vec3` 颜色，再补上 Alpha。

## 提示 3

目标形式是 `vec4(mix(color_a, color_b, UV.x), 1.0)`。

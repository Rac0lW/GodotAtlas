# P01 · 让像素发光

Shader 会为画面上的每个像素计算一个结果。先不急着学坐标，只要把固定颜色写进 `COLOR`，确认代码、预览和验证的流程都能跑通。

## 任务

把画面输出为目标 RGBA `vec4(0.12, 0.78, 0.72, 1.0)`。

四个分量的范围都是 `0.0` 到 `1.0`，按 8 位通道换算约为 `RGB(31, 199, 184)`，Alpha 为 `255`。这里的数值比“青绿色”这个名称更准确。

## 验收

- `COLOR` 的目标值是 `vec4(0.12, 0.78, 0.72, 1.0)`。
- Alpha 为 `1.0`，画面完全不透明。
- 验证器按渲染结果与该目标值的数值误差判断，不按颜色名称判断。

## 提示 1

片元阶段写在 `fragment()` 函数里。

## 提示 2

使用 `vec4(r, g, b, a)` 表示颜色。

## 提示 3

把最终颜色赋给 `COLOR`。

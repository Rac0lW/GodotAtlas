# P05 · 看见三维对象

空间 Shader 使用 `ALBEDO` 表示物体的基础颜色。这里先不计算光照，只把一个简单颜色放到球体上，为主课第 3 题做准备。

## 任务

让球体显示为 `ALBEDO = vec3(0.35, 0.58, 0.76)`，并保持 `unshaded`。

## 验收

- 球体的基础颜色是 `vec3(0.35, 0.58, 0.76)`。
- 旋转预览相机时，球体仍然可见。
- 结果不受灯光明暗影响。

## 提示 1

空间 Shader 的类型是 `spatial`。

## 提示 2

`ALBEDO` 接受 `vec3` 颜色。

## 提示 3

在 `fragment()` 中写入 `ALBEDO = vec3(0.35, 0.58, 0.76);`。

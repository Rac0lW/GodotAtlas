# P02 · 读懂 UV

`UV` 是从左上角到右下角变化的二维坐标。把它写进颜色，就能直接看见坐标在画面上的方向。

## 任务

让红色通道使用 `UV.x`，绿色通道使用 `UV.y`，蓝色固定为 `0.35`。

## 验收

- 左侧比右侧更暗。
- 顶部绿色较少，底部绿色较多。

## 固定数值目标

目标表达式为 `COLOR = vec4(UV.x, UV.y, 0.35, 1.0);`，蓝色通道固定 `0.35`，Alpha 固定 `1.0`。

## 提示 1

`UV.x` 和 `UV.y` 的范围都是 `0` 到 `1`。

## 提示 2

用 `vec4` 组合红、绿、蓝和 Alpha。

## 提示 3

最终结果仍然写入 `COLOR`。

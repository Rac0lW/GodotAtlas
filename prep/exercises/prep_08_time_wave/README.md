# P08 · 让图案动起来

`TIME` 是 Godot 提供的连续时间信号。配合 `sin`，可以得到可重复、不会跳变的周期动画。

## 任务

用 `sin(UV.x * 6.283 + TIME)` 生成横向波形，把它映射到 0 到 1，并让绿色通道继续显示 `UV.y`。

## 验收

- 画面从左到右出现连续的亮暗波形。
- 波形会随时间平滑移动，而不是随机跳动。
- 绿色通道仍能看出从上到下的 UV 渐变。

## 提示 1

`sin` 的结果范围是 -1 到 1。

## 提示 2

用 `0.5 + 0.5 * sin(...)` 把它变成 0 到 1。

## 提示 3

把波形放进 `vec4(wave, UV.y, 0.2, 1.0)`。

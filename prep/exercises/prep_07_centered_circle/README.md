# P07 · 中心坐标与圆形

UV 的原点在左上角附近。把它减去 `vec2(0.5)` 后，画面中心就变成新的原点，距离函数也更容易表达圆形。

## 任务

用 `length(UV - vec2(0.5))` 计算到中心的距离，并用 `smoothstep` 生成半径约为 0.23 的白色圆形。

## 验收

- 圆心位于预览中心。
- 圆内接近白色，圆外接近黑色。
- 圆的边缘有一条窄而连续的过渡带。

## 提示 1

先声明 `vec2 centered = UV - vec2(0.5);`。

## 提示 2

`length(centered)` 就是像素到中心的距离。

## 提示 3

用 `1.0 - smoothstep(0.22, 0.24, distance)` 把距离变成圆内为 1 的遮罩。
